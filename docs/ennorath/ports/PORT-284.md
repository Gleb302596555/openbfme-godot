# PORT-284 · Допустимые значения при загрузке снимка логики

На базе `3d017a41` у `closed_sets.py` 59 замечаний. Из них к этой части относятся 27 передач в шести файлах и одна устаревшая запись (`checksum`). Источник границ — **потребитель** поля. Адреса ниже перечитаны по RotWK 2.01 (`rw.py dis`, md5 `daed3668006cd90f01c34e5a7da1901f`). Это не перенос обработчика плохих сейвов из retail: именованный `XferException` — контракт нативного снимка OpenBFME (`SAVES.md`, §8). Меняется загрузка, но не порядок, ширина или версия записываемых полей.
