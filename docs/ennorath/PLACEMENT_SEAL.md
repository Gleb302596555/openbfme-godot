# Building placement seal / bib (Port 170, P-106)

Status: **the shared legality path is fixed; the reported taint colour is not a RotWK rule.** The owner clarified on the issue (2026-11-13): "the seal" is the placement marker, choosing its colour by the legal-build code is right, and what he calls the bug is a legality code that changes between neighbouring frames with a still cursor. That expectation replaced the earlier "red off tainted ground / white on it", which the reading below shows RotWK does not have.

## What the fix touches in the mod

The rule fires for a build template that is KindOf `WALL_HUB` **and** carries a `WallHubBehavior` row; a WALL_HUB template without that behaviour stays legal everywhere (RW's finder answers null). In the merged Ennorath data the furnaces (`IsengardFurnace`, `IsengardFurnacePlayer`) are the structures that carry `WALL_HUB`, so they are the ones whose seal can now turn the code-9 blue and whose click can now be refused beyond their `MaxBuildoutDistance`; `IsengardArmory`, `IsengardSiegeWorks`, `IsengardUrukPit`, `IsengardWargPit` and `IsengardLumberMill` keep the token commented out and are unchanged. Wall spans keep working through the shared function (their planner's own copy of the test is the hub-side variant with the command-button options, which the read of RW 0x797A96 keeps).

## The flicker: what the probe says

`engine/tests/test_port_170.cpp` (three `PORT-170` cases, synthetic INI and synthetic objects) drives the port's own judging path the way the device does - `advanceClientFrame` in the 30 Hz catch-up steps of 1 and 2, `judge = logicHeld()` alternating, the pointer parked, with and without `runLogicFrame` between the render frames - and records `InGameUI::placeLegalCode()` every frame, inside the painted taint disc and outside it. The recorded code never changes frame to frame (0 on a legal site, 9 beyond the hub range, and the same value with the logic stepping). The frame-parity gate alone therefore cannot be the alternation: it delays a judgement, it does not flip one. The red / white the owner sees must come from a state that changes between two judgements in a running game (a moving builder or an object entering the site - both are judged afresh every odd frame, as in retail) or from the presentation of the marker itself; that is outside this path and is recorded as stop S-7326.
