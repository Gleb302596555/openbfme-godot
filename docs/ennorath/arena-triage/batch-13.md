## Источники и границы

- Анализ только 30 полей issue #23, в его порядке. Код не изменялся.
- Проверен предоставленный RotWK 2.01 `game.dat`: MD5 `daed3668006cd90f01c34e5a7da1901f`.
- Мод `ennorath-ini-1.9.8.2.zip` распакован в `/tmp` и проверен первым: для всех 30 имён найдены активные (незакомментированные) присваивания в INI мода. Значения INI не публикуются; ваниль вместо мода не использовалась.
- Строка таблицы полей — четыре DWORD: имя, парсер, userData, offset. **Адреса строк таблиц — данные PE, не инструкции.** Содержимое строк проверено в PE; инструкции парсеров и читателей прочитаны через `tools/mod/rw.py ... dis`.
- **INFERENCE (для всей таблицы):** функциональные имена, смысл ветвей и принадлежность «клиент/логика» — статическая интерпретация дизассемблированного кода, не результат запуска игры. Наличие парсера, конструктора, копии или xfer не считается доказательством игрового использования. Отрицательных вердиктов без полного перечня читателей нет.

- `RotWK читает (логика)`: **6** — `TeamsWealthyRate`, `Wealthy`, `WaitForOthers`, `ResourceGatherersEasy`, `ResourceGatherersNormal`, `ResourceGatherersHard`.
- `RotWK читает (клиент)`: **16** — `UseLowLODTrees`; `DryLevel`, `ReverbEffectLevel`, `ZoomedInOffscreenOcclusionPercent`; `AudioFootprintInBytes`, `AutomaticSubtitleDurationMS`, `AutomaticSubtitleLines`, `AutomaticSubtitleTextColor`, `EmergencyResetTimeSeconds`, `ForceResetTimeSeconds`; все шесть `Global*ReverbMultiplier` этой пачки.
- `RotWK не использует`: **0**. Полного доказательства отсутствия чтений ни для одного поля не получено.
- `не определено`: **8** — `VehiclePathfindDiameter`, `WallHeight`, пять полей `/SkirmishBuildList/Structure` (`Angle`, `AutomaticallyBuild`, `InitiallyBuilt`, `Location`, `Rebuilds`), `AutomaticSubtitleWindowWidth`. Для каждого указан последний закрытый адрес и место остановки.

Кандидаты в задачи TOP20 (поля, которые RotWK читает; `TOP20.md` не менялся):

- Логика ИИ: пара `Wealthy` + `TeamsWealthyRate` (одна ветка RW 0x8F822D), `WaitForOthers` (RW 0x74B85F), тройка `ResourceGatherers*` (одна функция RW 0x8F73D6) — разумно две-три задачи механизмами, а не по полю.
- Клиент/звук: множители реверберации массивом +0xC4 (геттер RW 0x452754) — одна задача на весь массив; субтитры (`DurationMS`/`Lines`/`TextColor`, RW 0x450CED) — одна задача; `ForceResetTimeSeconds`/`EmergencyResetTimeSeconds` — одна задача сброса аудиоустройства; `DryLevel`/`ReverbEffectLevel`/`ZoomedInOffscreenOcclusionPercent` (RW 0x7767A9) — одна задача; `AudioFootprintInBytes` и `UseLowLODTrees` — по одной небольшой задаче.

**INFERENCE:** все описания игровой семантики — статический анализ; отдельно помечены в строках. Запуск игры, проверка достижимости конкретных определений мода и численных эффектов не выполнялись (установки игры в песочнице нет). Сборка и тесты движка не запускались — задача только анализа, код не менялся.

Остаётся: 8 незамкнутых цепочек (особенно потребитель списка TAiData +0xF8 для SkirmishBuildList и читатели `WallHeight`/`VehiclePathfindDiameter` в Pathfinder) и независимая проверка адресов рецензентом.
