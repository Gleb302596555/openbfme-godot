# Field triage 17/25 — предварительный результат

Источник: предоставленный `game.dat`, MD5 `daed3668006cd90f01c34e5a7da1901f`, оговорка S-001. Строки таблиц — **данные PE**, не инструкции; их расположение и четыре слова строк проверены поиском указателей в образе PE. Адреса кода ниже просмотрены `tools/mod/rw.py dis`.
