# Port 278 (issue #645): почему пять красных кнопок — честные NO-TARGET / BY-DESIGN (решения владельца от 2026-11-18; сцены свипа не меняются)

Вердикты: три кнопки рога Боромира — BY-DESIGN по данным мода (ритейл тоже ничего не применяет), две остальные — NO-TARGET (сцена свипа не содержит целей; в игре в Дорвинионе / Рохане модификатор применяется). Движок идентичен RotWK 2.01 на всём пути; подробно с адресами — `docs/ennorath/PORT278_ANALYSIS.md`.

- `DorwinionNaturmagier Command_SpecialAbilityNaturmagierErntesegen` (FactionElves): фильтр `ANY +ElvenMallornTree ALLIES` — `+ElvenMallornTree` имя шаблона, а не KindOf (include-KindOf-маска пуста); правило `ANY` отвечает «нет» всем, кроме шаблона-тезки по эквивалентности имён (шаг 4, RW 0x73D5C2), а ElvenMallornTree в сцене свипа нет — применять модификатор некому. NO-TARGET принят владельцем 2026-11-18.
- `GasthausGhanBuriGhan Command_SpecialAbilityGeheimeWege` (FactionRohan): фильтр `NONE +DruedainKrieger +DruedainKriegerHorde +DruedainWeiserBanner ALLIES` — include-KindOf-маска пуста, правило `NONE` требует непустую include-KindOf маску (RW 0x7638F6..0x7638FD), по KindOf не проходит никто; матчатся только названные друэданы по эквивалентности имён (шаг 4, RW 0x73D5C2), а в сцене свипа Рохана друэданов нет. NO-TARGET принят владельцем 2026-11-18.
- `GondorBoromir_mod Command_SpecialAbilityBoromirHorn` (FactionMen): в `ModuleTag_HornStarter` нет `AttributeModifierAffects` — фильтр заменяется конструктором на NONE с двумя пустыми масками (RW 0x89693A/0x89693D -> RW 0x763D11), матча нет ни с кем; список `BoromirGondorHornAntiCategory` пуст (только `Duration = 5000`, ни одной `Modifier =` строки). Так в данных мода (BY-DESIGN); в ритейле кнопка тоже ничего не применяет. Владельцем принято 2026-11-18.
- `GondorBoromir_OneRing Command_SpecialAbilityBoromirHornRing` (FactionMen): то же самое (тот же `ModuleTag_HornStarter`, та же `SpecialAbilityHornOfGondor02`, тот же пустой `BoromirGondorHornAntiCategory`). BY-DESIGN по данным мода; в ритейле кнопка тоже ничего не применяет. Владельцем принято 2026-11-18.
- `GondorBoromir_mod_ElrondsRat Command_SpecialAbilityBoromirHorn` (FactionImladris): то же самое (тот же `ModuleTag_HornStarter` в блоке ElrondsRat, `SpecialAbilityHornOfGondor02`, пустой `BoromirGondorHornAntiCategory`). BY-DESIGN по данным мода; в ритейле кнопка тоже ничего не применяет. Владельцем принято 2026-11-18.
