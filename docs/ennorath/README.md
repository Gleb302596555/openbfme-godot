# Порт Ennorath: с чего начать

Цель: Ennorath 1.9.8 на движке OpenBFME ведёт себя так же, как на RotWK 2.01. Мод не правится, чиним общий механизм движка.

## Порядок работы

Решение владельца, 2026-11-02:

1. [Проверка всех кнопок](BUTTON_SWEEP.md): что происходит при нажатии каждой кнопки каждой фракции.
2. [Подсистемы](SUBSYSTEMS.md): порт механизмов, сгруппированный по причинам.
3. Проход по фракциям A–G из [плана](../ENNORATH_FACTION_PLAN.md) как приёмка, а не поиск ошибок.

Записи в [PROBLEMS.md](PROBLEMS.md) это симптомы: они привязываются к подсистемам и закрываются вместе с ними. Прямое поручение владельца важнее этого порядка.
