## Blocked in Port 328 (issue #845)

S-144 (both sub-parts) is a data-load mechanism: its correctness is the exact replace/link split and the GlobalData gate, and both are
defined only by RW 0x5FE852 and its callees. This session ran without the RotWK 2.01 binary (the sandbox holding the extracted `game.dat`
did not persist; only this repository is durable), so the functions could not be read and no RW evidence was produced. Implementing the
behaviour from the STOPS row's one-line description would be a guess in exactly the place the row asks for evidence. Nothing was changed;
`PlayerTemplateStore::unverified()` keeps its `[S-144]` line.
