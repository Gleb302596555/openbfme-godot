## Why the branch matters and why it stayed

`RW 0x005B4B9A` is reached once per subsystem from `GameEngine::init` (the once-only byte at
`[0xDE3ED8]`, call site `0x00620E4E`). RotWK's own legend
(`Data\INI\Default\SubsystemLegendExpansion1.ini`) names only files its archives hold, so the branch
is dead in retail and in Ennorath 1.9.8; it becomes live as soon as a mod's legend and its archives
disagree, which is exactly the situation the port's BFME2 mode is in (RotWK's load order over BFME2
1.06 archives, `kBfme2SubsystemLegendFile`). The port currently answers that with an exception out
of `RunSubsystemIniLoad`, i.e. no game, where retail starts with the subsystem's hard-coded paths
(the `false` return is what tells the caller to use them).
