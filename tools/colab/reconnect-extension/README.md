# Colab Reconnect

Расширение браузера для песочниц OpenBFME в Colab Pro. Когда Colab показывает окно «Подключение к среде выполнения прервано», расширение сразу нажимает «Подключиться повторно» («Reconnect» в английском интерфейсе). Сессия продолжается та же. Раз в минуту оно ещё и само проверяет страницу. По клику на значок расширения виден журнал: когда и на какой вкладке оно нажимало.

Оно работает, только пока вкладка Colab открыта, можно в фоне.

## Chrome и Edge

1. Открой `chrome://extensions` (в Edge `edge://extensions`).
2. Включи «Режим разработчика».
3. Нажми «Загрузить распакованное» и выбери эту папку: `tools/colab/reconnect-extension`.
4. Перезагрузи вкладки Colab.

Расширение остаётся установленным после перезапуска браузера.

## Firefox

Обычный Firefox постоянно ставит только подписанные расширения. Поэтому:

- **Временно, до перезапуска Firefox.**
  1. Открой `about:debugging#/runtime/this-firefox`.
  2. Нажми «Загрузить временное дополнение» и выбери `manifest.json` из этой папки.
  3. Перезагрузи вкладки Colab.
- **Постоянно.** Есть два пути:
  - **Firefox Developer Edition или ESR.** В `about:config` поставь `xpinstall.signatures.required` = `false`. Потом запакуй содержимое папки в zip (файлы в корне архива), переименуй его в `.xpi` и открой через `about:addons` → шестерёнка → «Установить дополнение из файла».
  - **Подпись на addons.mozilla.org.** Нужен аккаунт; выбери самостоятельное распространение (unlisted).

## Проверка

На вкладке Colab нажми F12 → «Консоль». После загрузки страницы там будет строка `[colab-reconnect] watching this Colab tab`.

Когда расширение нажмёт кнопку, в консоли появится `pressing "Подключиться повторно"`, а запись — в журнале значка.

Если у тебя стоит ещё и userscript `tools/colab/colab_reconnect.user.js`, выключи его в Tampermonkey.
